Hari ini saya belajar tentang: struktur asas Artificial Neural Network (ANN) termasuk konsep input layer, hidden layer dan output layer, serta bagaimana neuron, weight dan bias berfungsi dalam menghasilkan output sesebuah rangkaian neural.

Perkara yang saya paling faham ialah: cara mengira output setiap neuron menggunakan formula z = x × w + b, serta bagaimana nilai weight yang berbeza mempengaruhi besar kecilnya output walaupun input yang diberikan adalah sama. Saya juga faham peranan setiap layer — input layer menerima data mentah, hidden layer memproses maklumat tersebut, dan output layer menghasilkan keputusan akhir.

Perkara yang saya masih kurang faham ialah: bagaimana fungsi pengaktifan (activation function) seperti ReLU atau sigmoid berfungsi dalam sesebuah neuron, proses backpropagation untuk melatih rangkaian neural, serta bagaimana ANN sebenar menyesuaikan nilai weight dan bias secara automatik semasa proses pembelajaran (training).

Saya akan meningkatkan pemahaman dengan: membuat lebih banyak latihan pengiraan manual untuk output neuron, mencuba menjalankan kod Python di Google Colab untuk melihat bagaimana perubahan input dan weight mempengaruhi output, membaca bahan rujukan tambahan mengenai fungsi pengaktifan dan backpropagation, serta melukis rajah ANN sendiri untuk pelbagai senario supaya lebih memahami struktur rangkaian neural secara visual.
